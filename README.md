# StyleCircle

A full-stack illustrated digital wardrobe, styling and social fashion project.

**Read [README_FIRST.md](README_FIRST.md) before replacing an existing project.**

Frontend: React 19 + Vite, Three.js, React Three Fiber, MediaPipe body landmark analysis.
Backend: Node.js + Express + MongoDB/Mongoose, JWT authentication, private GridFS clothing photos.

Includes My Closet, Outfit Builder, intelligent Mix & Match with locked pieces, FitCheck voting,
Virtual Fitting Room (photo previews + approximate 360 body avatar), calendar planner,
packing lists, wishlist, moodboards and wardrobe insights.

This repository is educational/prototype software, not a claim of photorealistic 3D body reconstruction.
